# สุ่ม G-code

เมื่อเปิดเว็บจะแสดงปุ่ม **สุ่ม G-code** ไว้กลางหน้าจอเพียงปุ่มเดียว หลังจากกด ปุ่มจะหายไปและ G-code จะสุ่มสลับเร็วแล้วค่อย ๆ ช้าลงประมาณ 7 วินาที ก่อนหยุดที่รายการหนึ่ง ข้อความ G-code แสดงขนาดใหญ่เต็มหน้าจอ สุ่มจากข้อมูลรวม 40 รายการ

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บ
- `styles.css` — รูปแบบหน้าเต็มจอและตัวอักษร G-code ขนาดใหญ่
- `app.js` — แสดงลูกเล่นสุ่มแบบชะลอความเร็วและเลือก G-code สุดท้าย
- `dataset.js` — ข้อมูลสำรอง 40 รายการสำหรับเบราว์เซอร์ที่บล็อกการอ่านไฟล์ Markdown ในเครื่อง
- `g_code_detective_activity_dataset.md` — ไฟล์รวมชุดข้อมูลที่ 1 และ 2 (รายการ 1–40)
- `g_code_detective_activity_dataset_v2.md` — ไฟล์ต้นฉบับของชุดข้อมูลที่ 2

## เผยแพร่ด้วย GitHub Pages

อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repository โดยวาง `index.html` ไว้ที่โฟลเดอร์ราก จากนั้นเปิด **Settings → Pages**, เลือก **Deploy from a branch**, ตั้ง branch เป็น `main` และโฟลเดอร์เป็น `/(root)` แล้วกด **Save**.

หากแก้ข้อมูลใน Markdown ให้ปรับข้อมูลสำรองใน `dataset.js` ให้ตรงกันด้วย.
